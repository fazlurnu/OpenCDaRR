# decisions

Architecture Decision Records (ADRs) — the **why** behind a choice, written when the choice
is made. E.g. why we own the geodesy rather than depending on BlueSky (0003), why this
multi-aircraft coordination model (0004), why this IPS level function (0017). One numbered file per
decision (`0001-...md`), 18 so far, no gaps.

They are dated and append-only: an ADR records what was decided *then*, so several describe code
that has since been superseded. `vault/architecture-dataflow.md` is the current picture; an ADR is
the reason it got that way.
